Cómo restaurar un backup
  1. Sube el archivo JSON al servidor en una carpeta accesible
  2. Ejecuta: docker-compose exec web python manage.py loaddata backup_encomiendas_*.json
  3. Verifica que los datos se hayan cargado correctamente
  4. ⚠️ Importante: Realiza backups regularmente, idealmente cada semana
